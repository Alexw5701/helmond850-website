# Helmond850.nl — Van de Aa naar de wereld

Onafhankelijke particuliere website over de wereldwijde verbindingen van Helmond. Het domein is afzonderlijk ter overname aangeboden via de bestaande MijnDomein-link.

## Nieuwe pagina's
- index.html: startpagina met aftelklok.
- wereld.html: interactieve wereldkaart en doorzoekbare verhalen.
- gemaakt-in-helmond.html: bedrijven en producten met wereldbereik.
- helmonders.html: internationale contacten en bewonersinitiatieven.
- naam-helmond.html: plaatsnaam, familienaam, historische duiding.
- geschiedenis.html: korte tijdlijn, toegang tot oorspronkelijke historische pagina's.

De bestaande pagina's tijdlijn, verhalen, erfgoed, jubileum, over en overname blijven beschikbaar. Overname-URL is intact.

## Privacy en uitvoering
Statische GitHub Pages-site, geen externe kaarten, cookies, trackers of gebruikersformulieren. Toegang via het bestaande CNAME-bestand; DNS niet gewijzigd.
