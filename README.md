# Helmond850.nl — onafhankelijke historische website

Een zelfstandige, statische website in het Nederlands, gemaakt voor publicatie op GitHub Pages. De site verzamelt geen aanmeldingen en laadt geen externe scripts, lettertypen of trackers.

## Inhoud

- `index.html`: startpagina
- `tijdlijn.html`: interactieve tijdlijn met doorzoekbare gebeurtenissen en bronverwijzingen
- `verhalen.html`: vijf historische artikelen
- `erfgoed.html`: musea, archieven en fotobronnen
- `jubileum.html`: nuance over 1178, 1108, 1179 en Helmond 800
- `over.html`: onafhankelijkheid, bronnen en privacy
- `overname.html`: bescheiden informatie over de mogelijkheid tot domeinovername
- `assets/`: volledig lokale stylesheet, JavaScript en eigen vectorillustraties
- `CNAME`: toekomstige koppeling aan helmond850.nl

## Publiceren via GitHub Pages

1. Maak op het GitHub-account `Alexw5701` een **nieuwe, afzonderlijke repository** aan, bijvoorbeeld `helmond850-website`. Gebruik de bestaande NoodNet-repository niet.
2. Upload de volledige **inhoud** van deze map naar de hoofdmap (`main`) van die nieuwe repository, inclusief `CNAME`.
3. Open **Settings > Pages**, kies `Deploy from a branch`, `main` en `/(root)`, en sla op.
4. Stel bij de DNS-provider in dat het apex-domein `helmond850.nl` naar de door GitHub Pages aangegeven IP-adressen verwijst. Gebruik altijd de actuele GitHub-documentatie (https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site) en controleer bestaande MX/TXT-records vóór wijzigingen.
5. Stel onder GitHub Pages de custom domain `helmond850.nl` in, controleer DNS en wacht op HTTPS-certificaat. Kies daarna waar mogelijk `Enforce HTTPS`.
6. Test beide domeinvormen `helmond850.nl` en `www.helmond850.nl`; stel desgewenst een alias in voor `www`.

**Belangrijk:** de website is nog niet gepubliceerd door alleen deze map te downloaden. De DNS-instellingen zijn nog niet gewijzigd. Publiceer alleen na inhoudelijke controle door de eigenaar.

## Nog te bevestigen

- Gegevens voor eventueel contact of colofon; publiceer geen persoonlijk e-mailadres zonder toestemming.
- Aanvullende historische foto’s na expliciete licentiecontrole.
- Definitieve keuze over redactionele updatefrequentie en eventuele officiële jubileumactiviteiten (hier niet als bevestigd gepresenteerd).

## Historische nuance

In 1978 vierde Helmond 800 jaar met 1178 als referentie, maar wetenschappelijke bronnen noemen een vermelding van `Helmund` uit 1108 en pauselijke stukken 1179/1182. Stadsrechten vermoedelijk rond 1232 maar geen oorspronkelijke oorkonde bewaard. Daarom is 2028 op de website gekoppeld aan de *jubileumtraditie*, niet aan een bewezen stichtingsdag.
